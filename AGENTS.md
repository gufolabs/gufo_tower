# Gufo Tower — Agent Instructions

Web-based control plane for managing NOC cluster topology, node assignments, and service configuration. Backend: Python (peewee ORM, Tornado web server). Frontend: WebIX UI bundled with esbuild. Deployed via Docker or pip installable wheel.

## Compatibility

- **Python**: The project targets Python 3.10 and later. All submitted code must remain compatible with Python 3.10+. Do not use syntax or standard library APIs unavailable in Python 3.10.
- **WebIX**: The frontend targets **WebIX 3.1**. Do not use APIs introduced in newer WebIX versions.

## Dev environment

The canonical development environment is a **VS Code dev container** (`.devcontainer/devcontainer.json`, builds `Dockerfile` target `dev` — Python 3.10, Node 24, uv, Playwright, ruff, mypx). With it running, `./scripts/run-dev` forwards commands into the container via `docker exec`.

```bash
./scripts/run-dev pytest -v
```

Host-side alternative when no dev container is running:

- **Python**: `uv venv && source .venv/bin/activate && uv pip install -e ".[test,lint]"`
- **Node.js 24**: `npm ci` (or `npm install` for local development)

## Command wrapper

`./scripts/run-dev` **execs commands inside the running dev container** via `docker exec` — it is not a venv wrapper. If no dev container for this repo is running it exits with error `7`; start the container first.

Examples:

- `./scripts/run-dev pytest -v`
- `./scripts/run-dev ruff check -q src/ tests/`
- `./scripts/run-dev ruff format --check src/ tests/`
- `./scripts/run-dev mypy --strict src/`
- `./scripts/run-dev python scripts/build-generated.py`
- `./scripts/run-dev npm run build`

## Build & test

| Task | Command |
|------|---------|
| Lint JS | `./scripts/run-dev npm run lint` |
| Build UI | `./scripts/run-dev npm run build` |
| Lint Python formatting | `./scripts/run-dev ruff format --check src/ tests/` |
| Lint Python rules | `./scripts/run-dev ruff check -q src/ tests/` |
| Type check (local only) | `./scripts/run-dev mypy --strict src/` (not CI-active, commented out in `py-tests.yml`) |

| Build package | `./scripts/run-dev python -m build --sdist --wheel` |

## Project structure

```text
src/gufo/tower/     — Python backend (models/, api/, cli/, daemons/, contrib/)
src/ui/             — Frontend source (WebIX-based, *.js + index.html)
src/ui/generated/   — DO NOT EDIT: regenerated by scripts/build-generated.py
tests/              — Pytest tests; conftest.py sets up temp home + sqlite db
docs/               — MkDocs documentation (dev/ guides + user guide)
contrib/            — deployment configs (nginx, k8s, systemd)
```

## Conventions

- **Source layout**: `src/gufo/tower/` package. Import as `from gufo.tower.models.db import db`.
- **Commit messages**: imperative description with PR link, e.g. `Home dashboard (#94)` — no component prefix. Create pull requests via GitHub CLI (`gh`) only.
- **Python style**: 79-character line limit, Google-style docstrings, Ruff auto-fix enabled (except `F401`). Type annotations are checked locally with `mypy --strict`.
- **Imports**: Group as `stdlib → third-party → first-party` according to the isort configuration in `pyproject.toml`.

## Pitfalls

- **Generated files**: `src/ui/generated/version.js` and `src/ui/generated/sdl.js` are auto-generated. Run `./scripts/run-dev python scripts/build-generated.py` before building the UI if they need regeneration.
- **UI build output** goes to `build/ui/`, **not** `dist/`. The Hatch build hook (`hatch_build.py`) includes it in the wheel via `[tool.hatch.build.targets.wheel.force-include]`.
- **esbuild configuration** lives in `scripts/build-ui.mjs`. Entry points are `vendor.js` and `main.js`; output assets use `[name]-[hash]` naming.
- **CI** runs on **Python 3.10** with system `uv`. It filters editable installs from `uv export` (`grep -v -- "-e ."`) before dependency installation. Lockfile differences caused only by editable installs are generally not significant.
- **Legacy GitLab CI**: `.gitlab-ci.yml` predates the GitHub Actions migration (Python 2.7, `noc/tower` paths) — do not rely on it.
