# Contrib

This directory contains additional scripts, configuration files, and other resources that may help deploy and run Gufo Tower in different environments.

The contents are provided as examples and templates that can be adapted to specific deployment requirements.

## Available Resources

- **compose** — A Docker Compose template for deploying Gufo Tower in a containerized environment.
- **k8s** — Configuration templates for deploying Gufo Tower on Kubernetes.
- **nginx** — Configuration examples for integrating Gufo Tower with Nginx.
- **systemd** — Configuration examples for managing Gufo Tower with systemd.

These resources are optional and can be adapted to your environment as needed.
