# Supported Standards

Gufo Tower implements and is guided by the following standards:

## :simple-python: Python PEP

* [PEP8][PEP8]: Style Guide for Python Code
* [PEP561][PEP561]: Distributing and Packaging Type Information

## :simple-javascript: JavaScript Web APIs

* [Navigation API][NavigationAPI]: Client-side navigation and history management
* [Fetch API][FetchAPI]: HTTP requests from the browser
* [URL API][URLAPI]: URL parsing and manipulation

[PEP8]: https://peps.python.org/pep-0008/
[PEP561]: https://peps.python.org/pep-0561/
[NavigationAPI]: https://developer.mozilla.org/en-US/docs/Web/API/Navigation_API
[FetchAPI]: https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API
[URLAPI]: https://developer.mozilla.org/en-US/docs/Web/API/URL
