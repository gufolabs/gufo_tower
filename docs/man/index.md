# Gufo Tower CLI

Manpages for the `gufo-tower` command-line interface.

## Commands

| Command                            | Description              |
| ---------------------------------- | ------------------------ |
| [`gufo-tower inventory`](inventory.md) | Show Ansible inventory. |
| [`gufo-tower job log`](job-log.md) | Manage Gufo Tower job logs. |
| [`gufo-tower pull`](pull.md) | Pull repository. |
| [`gufo-tower version`](version.md) | Show Gufo Tower version. |
| [`gufo-tower web`](web.md) | Run Gufo Tower web server. |
