# Datacenters

A **Datacenter** represents a location where NOC nodes are installed.

In addition to defining the grouping and locality of nodes, a Datacenter allows you to configure proxy servers specific to the Datacenter.

## Accessing Datacenters

To access Datacenters, select the **Datacenters** item in the sidebar.
